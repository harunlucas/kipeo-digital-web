# Impact Build application review template

Internal use only — do not route this document publicly or link it from the app. Copy this template per application when reviewing against the criteria published on `/impact-build`.

## Application

- Reference:
- Submitted:
- Organisation / initiative:

## Eligibility check

- Applicant type matches the eligible categories (or a reasonable discretionary exception)?
- No missing required declarations?

## Problem clarity

- Is the problem clearly and specifically described?
- Is it a real, current problem rather than a speculative one?

## Potential benefit

- Who benefits, and how many / how significantly?
- Is the benefit plausible given the applicant's description?

## Digital suitability

- Is a website / platform / small system actually the right solution?
- Does it fall within the eligible project types on `/impact-build`?

## Achievable scope

- Can this realistically be scoped to a focused, small project?
- Any signs of scope that would balloon past what the initiative can support?

## Readiness

- Decision-maker named and credible?
- Readiness answers (discovery, content, third-party costs, post-handover maintenance) — any "No" or "Need to discuss" that would block delivery?

## Content availability

- Is required content available now, or realistically available on a workable timeline?

## Ownership after handover

- Can the applicant plausibly maintain the result after the support period ends?

## Third-party-cost readiness

- Has the applicant acknowledged responsibility for third-party costs (domain, hosting, etc.)?
- Any indication they cannot cover even modest recurring costs?

## Risks

- Anything that raises concern: vague answers, mismatched claims, unclear organisational legitimacy, unrealistic expectations?

## Clarification questions

- List specific questions to send if shortlisted.

## Recommendation

- [ ] Shortlist for clarification
- [ ] Decline this cycle
- [ ] Select (subject to written scope agreement)

## Conflict-of-interest note

- Any personal, professional or financial connection between the reviewer and this applicant? If yes, note it and have another reviewer decide.
